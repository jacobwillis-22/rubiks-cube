# Interactive Rubik's Cube

A standalone, browser-based Rubik's Cube simulator and solving guide.

## Run it

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Publish with GitHub Pages

1. Open this repository's **Settings**.
2. Select **Pages** in the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)` folder, then save.
5. After GitHub Pages finishes deploying, the site will be available at:

   https://jacobwillis-22.github.io/rubiks-cube/

## Files

- `index.html` — the complete interactive app.
- `.nojekyll` — tells GitHub Pages not to run Jekyll processing.

## Notes

This is a static site. All app code is contained in `index.html`.
